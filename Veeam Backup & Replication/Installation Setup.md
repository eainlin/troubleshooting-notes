# 🧰 Veeam Backup & Replication v12 – Installation Guide
### Date: 11-Jun-2026
### Author: Htoo Eain Lin

> ⚠️ **Important (Legal Notice)**
>
> I can’t help with cracked or pirated software or licenses. This guide shows **official, legal installation** and **proper license activation** (Trial, Community Edition, or paid license).

---

## 📋 Prerequisites

* Windows Server (recommended) or supported Windows OS
* Administrator privileges
* Internet access
* Supported hardware & hypervisor (VMware / Hyper‑V, etc.)

---

## Step 1️⃣ Download Veeam Backup & Replication v12 (Official)

1. Go to the **official Veeam website**.
2. Sign in or create a Veeam account.
3. Download **Veeam Backup & Replication v12**.

> ✔ Use only official sources to avoid malware and legal issues.

---

## Step 2️⃣ Install Veeam Backup & Replication

1. Run the installer **as Administrator**.
2. Choose **Veeam Backup & Replication**.
3. Accept the license agreement.
4. Install required components when prompted.
5. Complete the installation and reboot if required.

---

## Step 3️⃣ Start Veeam Services

After installation, make sure all Veeam services are running:

```powershell
services.msc
```

Check that:

* Veeam Backup Service
* Veeam Broker Service
* Veeam Cloud Connect Service

are **Running**.

---

## Step 4️⃣ Activate a Valid License (Recommended)

### Option A: Trial License

* Veeam offers a **free trial** with full features for a limited time.

### Option B: Community Edition (FREE)

* Free for up to **10 workloads**.
* Ideal for labs and small environments.

### Option C: Paid License

* Use your official license file from Veeam.

### How to Install the License

1. Open **Veeam Backup & Replication Console**.
2. Go to **Menu → License**.
3. Click **Install License**.
4. Select your valid license file.
5. Confirm and verify license status.

---

## Step 5️⃣ Verify License Status

* Check **Dashboard → License**
* Confirm:

  * License is **Valid**
  * Correct edition is shown
  * Expiry date (if applicable)

---

## ✅ Result

* Veeam v12 installed successfully
* Services running normally
* License activated legally and safely

---

## 📝 Notes

* Avoid cracked licenses (security & legal risk)
* Always keep Veeam updated
* Back up your Veeam configuration regularly
